# PatchBounty (@aegis) — Autonomous Multi-Agent Security Bounty & Zero-Leak Escrow Swarm

**Built by Atul Anand, Jeeya, and Vanshika for Fetch-A-Thon 3.0**

## Overview
PatchBounty (`@aegis`) coordinates **6 specialized Fetch.ai `uAgents`** (`@aegis`, `@recon`, `@specter`, `@forge`, `@warden`, `@vault`) plus **3 autonomous researcher patch tiers** (`@blade`, `@kestrel`, `@titan`) to inspect complete source code across Python, JavaScript/TypeScript, Solidity, Java, Go, PHP, and C/C++, verify real exploits and fixes inside isolated sandboxes, negotiate against live industry bounty benchmarks (`NIST NVD` + `HackerOne / Immunefi`), and settle bounties on **Fetch.ai Dorado Testnet (`0.05 TESTFET`)** with live wallet balance tracking and official Block Explorer verification.

## Key Capabilities
1. **Clean / Bug-Free Code Safe Pass (`$0` / Zero Lock):** Clean source code or clean GitHub repositories never lock or request payment — immediate green safe verification.
2. **Zero Upfront Budget Bias + Live Market Benchmarks:** Researcher bids are anchored against real-world industry bounty benchmarks (`~90%+` savings) and support live multi-round bargaining on Step 3.
3. **Mandatory Sandbox Pass Gate + Blue Frosted Vault Lock:** Exact vulnerable line numbers and patched code remain sealed behind `HTTP 402` until `@warden` verifies `100% Exploit Blocked (PASS)` and `0.05 TESTFET` settles on Fetch Dorado (`dorado-1`).
4. **Live On-Chain Wallet Deduction & External Companion Explorer Links:** Displays live before/after `TESTFET` balances across Buyer (`fetch1...`) and Escrow Seller (`fetch1...`) wallets alongside direct Fetch Companion Block Explorer links.
